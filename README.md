# Сайт-подарок — v3

В этой версии исправлены именно те вещи, о которых ты попросил:

1. Реальное фото Next:
   положи фотографию в `assets/next.jpg`.

2. Вопросы:
   блок с вопросами **полностью отсутствует до нажатия на подарок**.

3. Анимация:
   до открытия в блоке справа существует только подарочная коробка.
   После клика коробка масштабируется и исчезает, затем на том же месте плавно появляется карточка с фото.

4. Фон:
   заменён на более аккуратные тонкие line-art котики, сердечки и лапки.

## Почта

В `index.html` замени:

`const FORM_ENDPOINT = "https://formspree.io/f/REPLACE_ME";`

на URL формы Formspree.

## Фото

Файл:
`assets/next.jpg`

Подойдёт обычный JPG или PNG (для PNG просто переименуй путь в HTML на `next.png`).

## Публикация

Подойдёт GitHub Pages, Netlify, Vercel или Cloudflare Pages.
